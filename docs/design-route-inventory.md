# Инвентаризация маршрутов для внедрения «Моих мест»

| Существующий маршрут или возможность | Точка входа в новом интерфейсе | Проверка |
|---|---|---|
| `/me/salons`, `/s/:code`, избранное и поиск | «Мои места», карточка салона и поиск под заголовком | Поиск имени и услуги, сохранение салона, прямой URL |
| `/me/bookings`, `/me/bookings/:id`, история и оценка | «Записи»: вкладки «Ближайшие» и «История», фильтр салона и даты; визиты также внутри салона | Запись, перенос, отмена, оценка и изменение оценки |
| `/s/:code/book`, `/me/bookings/:id/reschedule` | Услуга салона → выбор времени → серверный итог → подтверждение | Расчёт цены, выгода, конфликт слота и прямой URL |
| `/me/waitlist`, `/me/waitlist/new`, `/me/live-window/offers/:id` | Профиль и контекст записи/салона; предложение из событий и deep link | Создание, пауза, закрытие, принятие, отказ |
| `/me/loyalty`, `/me/offers`, `/me/events`, `/me/profile` | «Бонусы» и профиль; события из профиля и шапки на широком экране; настройки салона через поиск, выбор одного или «Все салоны» | Награды, акции, согласия, уведомления, тема и поиск салона |
| `/create-salon`, `/invite/:token` | Профиль и переключатель кабинета; прямая ссылка приглашения | Создание салона и принятие приглашения |
| Личный и рабочий кабинеты, демо-роли | Выбор кабинета в мобильной шапке; пункт «Сменить роль» в демо; рабочие кабинеты в профиле | Переход клиент → владелец и обратно на телефоне, проверка прав |
| `/work/:t/calendar`, `/work/:t/bookings/:id`, `/work/:t/bookings/new` | Месячный календарь → день → запись или ручная запись | Все/один мастер, другой месяц, роль мастера |
| `/work/:t/live-window` | Карточка отменённой записи и рабочие настройки | Конкретное окно, цепочка, остановка, настройки |
| `/work/:t/loyalty`, `/work/:t/partners`, `/work/:t/promotions` | «Лояльность» → свои и совместные программы; акции отдельно | Программы, версии, паузы, согласование и акции |
| `/work/:t/customers`, `/work/:t/customers/:id`, `/work/:t/catalog`, `/work/:t/schedule` | Рабочее меню | CRM, услуги, сотрудники и графики |
| `/work/:t/settings`, `/work/:t/staff-access`, `/work/:t/analytics`, `/work/:t/audit` | Рабочее меню и настройки | Витрина, доступ, статистика, журнал, ссылка и QR |

Прямые URL и MAX deep links сохраняются. Интерфейс использует действующие API и серверную проверку прав.
