# Лояльность и временные акции

## Для владельца салона

В рабочем кабинете откройте **Лояльность → Новая программа**. Выберите услугу, число платных завершённых посещений до награды и один вид награды: скидку в рублях, процент или число бесплатных посещений. Можно задать начало, окончание, срок самой награды и общий лимит выдачи. Пустые даты и лимит означают отсутствие ограничения. Программ для одной услуги может быть несколько: каждый подходящий визит пополняет каждую из них независимо.

После первой отметки условия программы закрепляются. Чтобы изменить награду, срок, лимит, услугу или порог, создайте новую программу; старую можно поставить на паузу или завершить. Выданные награды при этом сохраняются на прежних условиях. Счётчик лимита считает выданные экземпляры награды, а не бесплатные посещения внутри неё.

Партнёрская программа настраивается в разделе **Партнёрства**. Укажите исходные и целевые услуги, награду, период выдачи и условия. После предложения оба салона должны принять одну версию условий. Клиент отдельно соглашается с этой версией в разделе **Лояльность**. Новая версия требует нового согласия; уже выданные купоны сохраняют старые условия. Партнёрская награда выдаётся после каждого подходящего платного визита, отдельный порог посещений для неё не задаётся.

В разделе **Акции** владелец может сразу опубликовать скидку на свои услуги либо предложить скидку на услуги другого салона. Вторая акция станет доступной только после подтверждения салоном-исполнителем. Для каждой акции укажите обязательный период, услуги, размер скидки и при необходимости лимит применений. Салон-исполнитель финансирует скидку. Каждая сторона может поставить свою паузу; снять чужую паузу нельзя. Изменение опубликованных условий создаёт новую версию и требует повторного подтверждения партнёра.

## Для клиента

В **Лояльности** видны отметки отдельно по каждой обычной программе, выданные награды и согласия на партнёрские версии. В **Предложениях** видны партнёрские купоны и временные акции. При записи выберите одну выгоду: награду, купон или акцию. Итоговая цена отображается до подтверждения. Процент вычисляется от текущей серверной цены услуги и округляется до копейки. Скидка не может превысить цену услуги.

Награда с несколькими бесплатными посещениями применяется по одному разу к отдельным записям. Отмена и неявка возвращают неиспользованное посещение, если срок награды ещё действует. Платный визит даже со скидкой приносит отметки, если итоговая цена больше нуля; полностью бесплатный визит отметок не приносит. У обычной и партнёрской программы разные отметки/выдачи: согласие на партнёрскую версию не меняет обычную лояльность.

Настройки в **Профиле** и в предпочтениях салона управляют сообщениями бота о партнёрских предложениях. Они не заменяют согласие на конкретную версию программы.

## Проверка в демо

1. Владелец создаёт две программы на одну услугу с порогом 2 и разными наградами.
2. Сотрудник завершает два платных визита клиента. В его карточке появляются две независимые награды.
3. Клиент выбирает награду при записи; в расчёте видит скидку. Для бесплатной награды с несколькими посещениями можно сделать несколько отдельных записей, пока есть остаток.
4. Владелец публикует акцию с лимитом 1. После первой записи вторая попытка получает отказ по лимиту; после отмены первой записи лимит снова доступен в пределах исходного срока акции.
5. Для партнёрской программы клиент подтверждает конкретную версию условий **до** завершения визита. После смены версии согласие требуется заново.

Все проверки срока, услуги, салона, остатка и лимита выполняет сервер. Рабочие API для программ и акций доступны владельцу, выбор выгоды при записи — клиенту и сотруднику с правом оформления. Записи и события логируются в журнале аудита.
