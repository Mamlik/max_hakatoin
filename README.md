# Салон в MAX: Живое окно

Хакатонный проект для салонов и студий персональных услуг внутри MAX. Продукт объединяет клиентскую витрину, онлайн-запись, рабочий календарь и минимальную CRM.

Главная функция — «Живое окно»: если клиент отменяет визит, система находит подходящих людей из листа ожидания и помогает заполнить освободившееся время.

```text
отмена записи
→ поиск подходящих клиентов
→ подтверждение администратором
→ последовательные предложения
→ временное удержание слота
→ новая подтверждённая запись
```

## Что входит в MVP

- общий бот и mini-app MAX;
- изолированные пространства нескольких салонов;
- витрина салона, услуги, мастера и расписание;
- запись, перенос и отмена визита;
- защита от двойной записи и временный hold слота;
- минимальная карточка клиента и лист ожидания;
- полный сценарий «Живого окна»;
- уведомления, подтверждения критичных действий и журнал событий;
- показатель возвращённой потенциальной выручки;
- один AI-сценарий для разбора текста или голоса в черновик.

## Основные принципы

- AI предлагает структурированный черновик, но не меняет состояние бизнеса напрямую;
- критичные действия выполняются только после явного подтверждения;
- расписание и переходы состояний работают детерминированно;
- данные каждого салона изолированы;
- при недоступности AI обычная запись и «Живое окно» продолжают работать.

Технологический стек и архитектура будут определены отдельно. Предпочтительные варианты backend — Python или Kotlin; стек клиентской части пока не зафиксирован.

Подробные требования находятся в [salon-in-max-spec.md](./salon-in-max-spec.md).
